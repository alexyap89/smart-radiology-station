## 2. Rules that must not regress

`HANDOFF.md` §1–§4 still govern evidence: only the approved numbers, no fabricated comparisons, no unlabelled vendor material, radiologist as final interpreter. In practice:

- **Never invent a figure, a study size, a dose saving, or a patient quotation.**
- Three kinds of claim are labelled: *validated* (RbFracture audit), *live service* (3D Lab), *pilot / initial evaluation* (4D, MRI acceleration).
- Vendor material carries "Vendor example — not our data". Only one vendor image survives: the GE TrueFidelity tab on `#s-see`, which the owner supplied himself. If "no vendor data" is ever absolute, delete that tab and its entry in `SEE_CASES`.
- Clinical images are de-identified; portraits are labelled as illustrative.

## 3. Traps — each of these cost real time

1. **Cache.** `styles.css`, `app.js` and every `assets/**` URL carry a `?v=<stamp>`. Run `./bump.sh` before *every* commit that touches CSS, JS, images or clips. Three separate "fixes" looked broken because a stale stylesheet, poster or mp4 was being served. If a change appears not to apply, this is why — not the code.
2. **Never regex across `index.html`.** A pattern meant to restyle three control bars deleted four whole screens. Edit exact strings, assert the match count, and `grep` after. Recover with `git checkout -- index.html` if it goes wrong.
3. **Subagents have twice corrupted this repo** (one overwrote `index.html` with its own app; another reverted `app.js`). If you dispatch, require read-only briefs for reviews, and diff every file afterwards.
4. **Grid rows.** `.split` inherits `align-content: start`, which packs rows to their content height and leaves a void. `#s-speed`, `#s-pos`, `#s-neg` need `align-content: stretch` plus `height: 100%` on the split.
5. **Flex stages** that should absorb leftover height need `height: 0; flex: 1 1 auto; min-height: …`, otherwise the content inflates the row and the screen overflows.
6. **The 3D model** must request `webgl2` first — 32-bit indices are core there, and a device can offer WebGL2 while reporting no `OES_element_index_uint`. Its full-screen overlay has an exit button *inside* the overlay; Escape also closes it.
7. **Videos** autoplay per screen via `moveVideos()` / `playVideos()`. Leaving a screen must pause.
